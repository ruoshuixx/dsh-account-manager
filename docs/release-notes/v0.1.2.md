首个公开版本：DSH 账号管理，给 DeepSeek Harness（dsh）用的账号与供应商管理工具。

- 切换 dsh 内置的 Codex 账号，切号前把 dsh 刷新过的较新令牌写回加密账号库；在没有 Codex 路由的档案里会顺带启用 `openai-codex`。
- 管理 `cordis.patch.yml` 里的 API 供应商（新增 / 编辑 / 删除 / 换 Key）；删除或去掉模型前检查 dsh 设置里的引用，并提供修复和“撤销”。
- 导入 / 导出 Cockpit 格式 JSON，按接口地址 + Key 匹配已有供应商，不再新建重复项；额度查询、自动刷新、WebDAV。
- Windows 版：官方 DeepSeek Harness 桌面版（档案 desktop）；Ubuntu 版：dsh-tauri（档案 tauri）。
- 资产：`DshAccountManager-win-x64.exe`、`dsh-account-manager_0.1.2_amd64.deb`，各带 `.sha256`；程序内“检查更新”可升级。
