让 dsh 的主代理能把任务委派给你导入的模型。

- 每次导入成功后，自动把你的供应商 × 模型合并进 dsh 的 `subagent-model-selection-settings`（启用并写入 `allowedModels`），主代理即可把子任务交给这些 API 模型；你自己加的条目不会被改动，不会写重复项。
- 切号时首次启用内置 Codex 路由，会写入官方现行 Codex 模型（`gpt-6.1-sol`、`gpt-6-astra`、`gpt-6-luna`，只写 id）并把它们一并加入子代理可用模型；已有的 `openai-codex` 条目不动（0.1.2 写下的完全空条目会被补全成这份列表，补全前先备份），不会加入 gpt-6-sol、gpt-5.6 系列或已下线的 gpt-5.5 / gpt-5.3-codex-spark。
- 写入前先加密备份，在锁内回读校验；格式不认识的条目（行内写法等）会被拒绝修改，不会被重写。
- 改动只对 dsh 里的新对话生效：请在 dsh 中新建对话后，再让主代理调用子代理。
- 界面默认更紧凑：列表行、工具栏、对话框的间距收小，默认窗口 980×620、最小 860×480；在小屏幕高缩放比（如 1368×768 @175%）下缩得更少、字更大。过长的邮箱 / 供应商名称在自己的列内用省略号截断（鼠标悬停看全名），不再压住订阅信息；所有对话框都限制在屏幕内，内容较多时在对话框里滚动。
- WebDAV 云端目录改为中立的 `/AccountManager/`，写 Cockpit 格式 JSON 的其他工具可以共用（文件名前缀区分来源）。下载取该目录里最新的 `.json`，仍先进入导入预览；该目录没有文件时，才会读取旧目录 `/DshAccountManager/` 里的最新文件（只读，不改动）。
