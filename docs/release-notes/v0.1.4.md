Codex Fast 模式，不需要任何第三方插件。
- 自带一个很小的 dsh 插件 `dsh-account-manager-fast`，导入时自动装进 dsh 档案（不需要 dsh 命令行或联网，写之前先加密备份 package.json）。
- 在 `openai-codex` 路由里补上 `gpt-6.1-sol-fast`、`gpt-6-astra-fast`、`gpt-6-luna-fast`；选它们时请求以基础模型发出并带 `service_tier: "priority"`。
- 首次安装需要完全退出 DSH 再打开；Fast 按官方规则以 2.5 倍消耗订阅额度。
- 组件缺失时本工具写的 `-fast` 模型会自动移除，你自己写的条目不动；默认模型不改，子代理不会选 Fast 模型。
- 手动移除：删除档案里的 `node_modules/dsh-account-manager-fast` 文件夹和 `package.json` 里的对应名字。
