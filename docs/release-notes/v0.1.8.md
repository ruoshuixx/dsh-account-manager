供应商模板、OpenAI 思考程度与 Fast，以及几处修正（0.1.6 和 0.1.7 没有单独发布，这里一并带上）。
- 添加 / 编辑 API 的“供应商名称”改成可编辑的下拉框：OpenAI、火山 Coding Plan、火山 Agent Plan 三个模板。选中模板时，URL 和模型只在为空时才填入（已填的不动），协议只在 URL 被填入时跟着模板走；API Key 不动。仍可直接输入自定义名称。模型框下面一行说明会按当前地址和协议提示将自动配置什么。
- OpenAI 官方 API（`https://api.openai.com/v1`、Responses 协议）：GPT-6 系列模型自动配置思考程度 low / medium / high / xhigh / max（不写 none / minimal）；已有的 OpenAI 供应商在编辑里重新保存后补上，已有的档位不覆盖。火山方舟的档位规则不变。
- OpenAI 官方 API 的 Fast：添加 / 编辑时勾选“附带 Fast 模型”（新建默认勾选），会给每个 GPT-6 系列模型写一个 `<id>-fast`（名字“… (Fast)”，档位与基础模型相同；它们不出现在模型框里，勾选状态就是它们是否存在）。选用时请求以基础模型发出并带上 `service_tier: "priority"`，按 OpenAI 优先处理的更高单价计费。需要 Fast 组件 0.2.0：保存时会自动安装 / 更新到档案；组件首次安装或更新后需要完全退出 DSH 再打开才生效。装不上组件时不写 Fast 模型，其余照常保存并提示原因；组件缺失时本工具写入的 API Fast 模型会和 Codex 的一样被移除；子代理候选不含 Fast 模型。
- 修正：编辑 API 供应商时，接口地址偶尔显示为 `[REDACTED]`。编辑框改用档案里存的真实地址，列表里的地址只做格式脱敏；添加窗口也不再把输入的每个前缀登记为密钥（Key 仍在保存时登记）。
- 主界面工具栏新增“同时切 Codex”勾选（与设置里的开关同步）：切号时一并写入 Codex 的 `auth.json`。Codex CLI 与桌面版共用这个文件，已打开的桌面版需要重启才生效。

0.1.6：Codex 模型的上下文长度改用账号允许的最大值（`max_context_window`，今天是 872000），只改本工具写的条目，导入结果会写明改了哪些；上下文越长，每条消息消耗的订阅额度越多。

0.1.7：切号时同时切换 Codex CLI。设置新增“同时切换 Codex CLI”（默认开）和 Codex 主目录；写前加密备份、原子替换、保持 0600、保留其它键；先把 Codex CLI 刷新过的较新令牌写回账号库；账号列表里 Codex CLI 用的账号与 dsh 不同时显示“CLI”标记。
