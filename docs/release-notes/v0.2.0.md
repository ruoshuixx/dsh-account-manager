AI 账号管理 0.2.0：并入 OpenCode 切号，切换目标改成单选，应用显示名改为“AI 账号管理”。
- 新增：切号可以写给 **OpenCode**。把账号设为 OpenCode 里 `openai` 的当前 OAuth 凭据（已有同一账号的凭据就复用，必要时用账号库里较新的令牌更新；没有就新建并激活）。需要已安装 OpenCode；设置新增“OpenCode 命令路径”（留空自动检测，可浏览选择）。找不到 OpenCode 时切号会明确失败，不改任何东西。
- 工具栏“同时切 Codex”换成三个勾选框 **dsh / Codex / OpenCode**，永远只勾一个（点已勾的仍是勾着），设置会记住，默认 dsh。切号只写所选目标：dsh 只写 dsh 的凭据；Codex 只写 `auth.json`；OpenCode 只写 OpenCode。原因：同一个 refresh token 被多个程序同时用，其中一个刷新后别的会报 `refresh_token_reused`。
- 切号前先把 dsh、Codex `auth.json`、OpenCode 里同一账号较新的令牌写回账号库。如果要切的账号正被目标之外的程序使用，手动切号会先确认；自动切号直接跳过这类账号。
- 账号列表的“当前”标记跟着所选目标走；旧的“CLI”标记去掉。切号后状态栏写明切了哪个，例如“已切换 OpenCode 账号：…”。目标选 Codex / OpenCode 时，工具栏提示 API 列表仍是 dsh 的（下一版再按目标分开）。
- 设置：去掉“同时切换 Codex”开关（旧的 `SwitchCodexCliToo` 读到后忽略，下次保存时丢弃）；保留“Codex 主目录”。
- 改名：界面、安装包桌面项、托盘提示统一叫“AI 账号管理”。程序文件名、安装包名 `dsh-account-manager`、数据目录、账号库、升级用的仓库和资产名都没有变，旧版本可以直接在程序里升级。
- 迁移说明：原“OpenCode 账号管理”应用自己的数据（它的账号列表、设置、WebDAV 配置）这一版不会迁移，计划在后续版本处理；这一版只读写 OpenCode 本身的凭据。
- OpenAI 官方 API 的 GPT-6 模型补上官方上限：上下文（输入）92.2 万、输出 12.8 万、支持图片输入。之前 dsh 对没有内置资料的供应商用默认值 26.2 万 / 3.3 万 / 仅文字。只补缺的项，你自己设过的值不改；已有的 OpenAI 供应商在“配置”里重新保存一次即可补上。注意：单次输入超过 27.2 万 token 时 OpenAI 按长上下文价计费（输入 2 倍、输出 1.5 倍）。
- 新模板 **DeepSeek**（`https://api.deepseek.com`，Chat Completions；模型 `deepseek-flash` 即 V4.1-Flash、`deepseek-v4-pro`）。官方地址上的这两个模型自动配置思考程度 low / high / max，上下文 100 万、输出 38.4 万，`deepseek-flash` 支持图片、`deepseek-v4-pro` 仅文字。同样只补缺的项。
